## 🚀 One-Click Setup:

### Step 1: Go to GitHub
1. Open your web browser
2. Go to: https://github.com
3. Sign in with your Google account (or create account)

### Step 2: Find the Repository
1. Search for: `eduswap-backend-firebase`
2. Click on the repository
3. Click the green "Code" button
4. Click "Download ZIP"

### Step 3: Extract the Files
1. Go to your Downloads folder
2. Right-click on the ZIP file
3. Select "Extract All..."
4. Choose a location (like Desktop)

### Step 4: Deploy to Firebase
1. Open PowerShell in the extracted folder
2. Run: `firebase init`
3. Select your project
4. Run: `firebase deploy`
